# Darkmoon Turn-ins

Addon for WoW Forever. It shows which items serve a Darkmoon Faire turn-in quest.

## Install

```
make install WOW_DIR="/path/to/World of Warcraft/_forever_"
```

## Commands

- `/dmft` toggles the window.
- `/dmft minimap` shows or hides the minimap button.

## Optional addons

- Baganator
- Syndicator
